# Externes Playtest-Protokoll: Auto, Zielauftrag und Direkt

Stand: 24. August 2026

## Ziel

Der Test beantwortet eine Produktfrage: Welche Kontrollform verbindet
verständlich erlebte Agency, Figurenpersönlichkeit und unterhaltsames
Artillery-Chaos am besten?

Verglichen werden im selben Build:

- **Auto:** Die Figur entscheidet Ziel, Position, Waffe und Flugbahn.
- **Zielauftrag:** Der Spieler bestimmt pro Crewzug den Rivalen; die Figur
  entscheidet den Rest.
- **Direkt:** Der Spieler bestimmt erreichbare Position, Waffe, Winkel und Kraft.

Der Test bewertet nicht Grafikpolitur, Storymenge oder langfristige
Progression. Zielgröße sind zehn externe Personen; sechs sind das sinnvolle
Minimum für ein erstes Richtungssignal.

## Vorbereitung

- aktuelle öffentliche GitHub-Pages-Fassung in einem frischen Browserfenster,
- Querformat oder Desktop, Ton optional,
- pro Person etwa 25–35 Minuten,
- ein Moderator und ein leerer Erfassungsbogen pro Person,
- keine Erklärung der KI-Gewichte und keine Hinweise auf einen bevorzugten Modus.

Die Reihenfolge wird gegenbalanciert. Person 1 startet mit Auto, Person 2 mit
Zielauftrag, Person 3 mit Direkt; danach wird die Reihenfolge zyklisch
verschoben. So gewinnt nicht automatisch die zuerst gelernte oder zuletzt
gespielte Variante.

## Ablauf pro Person

1. Nur sagen: „Bitte probiere drei Steuerungsarten aus. Sprich laut aus, was du
   erwartest und was dich überrascht.“
2. Im Hauptmenü den zugewiesenen Modus wählen und
   `KERNLOOP-TEST · KONFLIKTZONE` starten.
3. Drei eigene Crewzüge oder bis Matchende spielen lassen. Nur bei echter
   Bedienblockade helfen; die benötigte Hilfe notieren.
4. Direkt danach die Kurzbewertung für diesen Modus erfassen.
5. Schritte 2–4 für die beiden anderen Modi wiederholen.
6. Anschließend ein Standardmatch im frei bevorzugten Modus beginnen und
   mindestens drei eigene Züge beobachten. Diese Wahl ist ein wichtiges
   Verhaltenssignal, aber kein einzelner Siegerbeweis.
7. Abschlussfragen stellen und besonders konkrete Momente notieren.

## Beobachtung während des Spiels

Der Moderator notiert ohne Interpretation:

- Kann die Person vor der Ausführung Ziel und beabsichtigte Wirkung benennen?
- Versteht sie, welche Entscheidungen Figur und Spieler jeweils treffen?
- Wird „Lass das!“ als semantisch andere Alternative verstanden?
- Wird mindestens eine Folge von Krater, Fasskette, Freundrisiko oder Ring-out
  vorausgesehen beziehungsweise nachträglich richtig erklärt?
- Schreibt sie eine überraschende Entscheidung einer Figur/Persönlichkeit oder
  nur „der KI“ beziehungsweise einem Fehler zu?
- Wo wartet, klickt oder fragt sie ohne zu wissen, wie es weitergeht?
- Bei welchem Moment lacht, ärgert oder freut sie sich sichtbar?

## Kurzbewertung nach jedem Modus

Alle Aussagen werden von 1 („gar nicht“) bis 5 („sehr“) bewertet.

| Aussage | Auto | Zielauftrag | Direkt |
| --- | ---: | ---: | ---: |
| Ich verstand, was als Nächstes passieren sollte. |  |  |  |
| Meine Entscheidungen hatten spürbare Folgen. |  |  |  |
| Die Figuren wirkten eigenständig und charaktervoll. |  |  |  |
| Überraschungen wirkten fair statt zufällig. |  |  |  |
| Terrain und Objekte waren taktisch relevant. |  |  |  |
| Ich wollte sofort noch einen Zug spielen. |  |  |  |

Zusätzlich je Modus offen fragen:

- „Welcher Moment war deine wichtigste eigene Entscheidung?“
- „Was hat die Figur entschieden – und warum glaubst du das?“
- „Was war unklar oder frustrierend?“

## Abschlussfragen

- Welchen Modus würdest du freiwillig für ein volles Match wählen? Warum?
- Bei welchem Modus hattest du am meisten Verantwortung für das Ergebnis?
- Bei welchem Modus waren die Figuren am stärksten eigene Charaktere?
- Welche einzelne Änderung würde deinen bevorzugten Modus deutlich verbessern?
- Würdest du freiwillig eine weitere Runde spielen?

## Auswertung und Entscheidungstor

Zahlen werden zusammen mit beobachtetem Verhalten und wörtlich notierten
Begründungen gelesen. Bei dieser kleinen Stichprobe sind Mittelwerte Hinweise,
keine wissenschaftliche Gewissheit.

- **Auto führt klar:** Selbsterklärende Planung und Figurenbindung sind stark,
  Agency bleibt ausreichend. Als Nächstes werden wenige semantische
  Managerkommandos vertieft.
- **Zielauftrag führt klar:** Das delegierte Ziel wird zum Kern; danach werden
  weitere kleine Aufträge nur einzeln prototypisiert.
- **Direkt führt klar und Figurenbindung bleibt erhalten:** Produktvision und
  Abgrenzung werden ausdrücklich neu entschieden, bevor Direkt zum Standard wird.
- **Kein klares Signal:** Die häufigste konkrete Blockade wird einmal klein
  behoben und mit denselben Fragen erneut getestet. Keine neue Vollkarte oder
  Contentmenge als Ersatz für die offene Kernfrage.

Ein „klarer“ Sieger benötigt ein konsistentes Muster: bevorzugte Moduswahl,
höhere Agency-/Wiederholungswerte und passende beobachtete Begründungen bei
mehreren Personen. Eine einzelne laute Meinung oder ein kleiner
Mittelwertunterschied reicht nicht.
